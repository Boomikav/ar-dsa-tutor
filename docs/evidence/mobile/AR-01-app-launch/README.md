# Test AR-01: Mobile Application Launch & Navigation

**Test Code:** AR-01  
**Category:** Mobile Deployment & App Shell  
**Objective:** Verify that the mobile browser can access the application over HTTPS, render the mobile responsive layout without horizontal overflow, and initialize state.

---

## Preconditions
1. Physical device connected via trusted HTTPS or Chrome USB port forwarding.
2. Web browser: Google Chrome on Android (or WebXR Viewer on iOS).

## Test Protocol
1. Navigate to application URL on the mobile device.
2. Observe Splash screen loading and transition to Onboarding / Home screen.
3. Verify bottom navigation bar displays and responds to touch taps.
4. Navigate to **Student Profile** and inspect the **Device AR Diagnostics** card.
